mailhub

A personal tool for triaging several email accounts, including Gmail, in one place.

What mailhub does

mailhub is a self-hosted email application built by Kiyoshi Sasagawa for managing his own email accounts. It runs on the author's own server and is used by the author.

  • Shows the inbox grouped by sender, so that newsletters and notifications can be archived or marked as read in bulk.
  • Searches all mail, including archived messages, and displays a message when it is opened.
  • Lets the author's own AI assistant perform the same triage actions on his behalf, with his permission.

How mailhub uses Gmail

mailhub connects to Gmail over IMAP using OAuth with the scope https://mail.google.com/, only after the author grants access with his own Google Account. It reads message headers and flags to build the inbox view, reads a message body when the author opens it, and moves or flags messages only when the author asks for it. See the privacy policy for details.
